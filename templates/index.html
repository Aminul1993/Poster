            Mode

            Ollama · AI generation

            Images are resized in the browser, sent to the Poster server as Base64, and analysed with Ollama's /api/chat. The endpoint and API key are set on the server.

            0 / 500

            Buffer · scheduling

            The server uses your Buffer personal access token with Buffer's GraphQL API. Connect to load your channels, then choose where posts go.

            Channels

            Media hosting

            Buffer has no upload endpoint: images are attached from public URLs. When a media host is configured on the server (Vercel Blob, or for example a Cloudinary unsigned preset), Poster uploads each image there and uses the returned URL. You can also paste a public URL for each image in the editor.

            Scheduling

            Content rules

            Hashtags: unique, at most 15 per post. Instagram allows 2,200 characters, X allows 280.

            Import, export & reset

            Your preferences, theme, drafts, schedules and the activity log are stored in this browser's localStorage. API keys and endpoints live only on the server and are never exported.
